Each comparison group has an illumos path list and an OpenZFS path list:

    <group>-illumos.txt
    <group>-openzfs.txt

The group files contain one path per line, without comments or blank lines,
so their contents can be passed directly as command arguments.

For core, platform, userland, and tests, line N in the illumos list maps to
line N in the OpenZFS list.  The two lists must have the same number of lines.
Files are counterparts only when their relative paths agree within one of
these mapped path pairs.  Earlier, more-specific mappings take precedence over
later, broader mappings.

core
    Core and shared ZFS implementation.

platform
    Platform-specific ZFS implementation.  OpenZFS separates its Linux
    implementation, while the corresponding illumos sources are mixed into
    the illumos core tree.  Therefore platform-illumos.txt is empty.

userland
    ZFS libraries and commands.  The OpenZFS list includes both file and
    directory forms of zhack and ztest because their layout varies across
    history.

tests
    ZFS test suites.  Keep this group separate so the large number of tests
    does not dominate sibling-similarity measurements.

exclude
    Unpaired integration, support, build, packaging, and documentation paths.
    These are reference paths, not a comparison group.  Exclude them from
    sibling-similarity measurements.  Exclusion entries may use Git
    `:(glob)` pathspecs.  Literal and glob exclusions take precedence over
    mapped roots.

exception
    Modifiers for files in the normal comparison groups that have known,
    intentional divergences.  Keep these files visible in reports but exclude
    them from sibling-similarity measurements.  Exception entries may use Git
    `:(glob)` pathspecs.

    illumos full NFS ACL support in
    usr/src/uts/common/fs/zfs/zfs_acl.c must be preserved.  The OpenZFS
    implementation was rewritten and should not affect sibling ranking.
